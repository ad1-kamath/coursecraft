# Security

## Reporting a problem

Please report security problems privately, not in a public issue: use **Security → Report a vulnerability** on the GitHub repository. Include what you found, how to reproduce it and which version you used.

You'll get a reply as soon as the maintainer can, usually within a week. Once a fix is released, the report can be made public with credit to you, if you like.

## What counts

- A course file (`.ccraft`, `course.json`, PowerPoint, XLIFF, CSV) that makes CourseCraft crash, hang, read or write files outside the project, or run code.
- A published package that lets a learner or another site reach data it shouldn't, for example through the LMS connection.
- AI provider keys or other secrets being stored or sent somewhere they shouldn't be.

## What CourseCraft does with your data

CourseCraft has no server and sends nothing on its own. The optional AI features send content only to the provider you configure, and tell you before they do. Help → Report a Problem opens a pre-filled page in your browser that you submit yourself.
