# Bug Hunt Review — CourseCraft 0.6.1 (Neon)

- **Baseline:** `v0.6.1` (branch `bughunt-neon-0.6.1`)
- **Scope:** Full workspace audit across runtime (`coursecraft-logic`, `coursecraft-render`, `coursecraft-player`, `coursecraft-lms`, `coursecraft-playback`), I/O/import/export/publish (`coursecraft-format`, `coursecraft-pptx`, `coursecraft-publish`, `coursecraft-scorm`, `coursecraft-xapi`, `coursecraft-export`, `coursecraft-cli`, `coursecraft-control`, desktop `files.rs`), engine & model (`coursecraft-engine`, `coursecraft-course`), LTI server (`coursecraft-lti`), and editor UI (`coursecraft-ui-egui`), checked against `docs/spec/triggers.md`, `docs/spec/course-model.md`, `docs/cli.md`, and `docs/ui/*.md`.
- **Exclusions:** All known issues (A1–A14, B1–B7, C1–C12, H1–H7) and the known environment-specific `bughunt_m26_a7` / `coursecraft-video-native` crash are omitted.
- **Proof tests:** 56 failing `#[ignore]` tests added across 12 `neon_bughunt_tests.rs` files (one per crate). The default test suite stays green; run `cargo test --test neon_bughunt_tests -- --ignored` in any crate to reproduce the failures.

## Checked and Working

- **Undo/redo delta engine (`crates/engine/src/delta.rs`)**: Exhaustive destructuring of `Course`, `Slide`, and `Layer`; `SlideDelta`, `CourseHeaderPatch`, `ListOp`, `StructuralOp`, `CourseDelta::Sequence`, and `merge` are self-inverting and diff after connector rerouting.
- **Trigger loop protection & core trigger/scoring engine (`crates/logic`)**: `MAX_EVENTS_PER_INPUT` (1024), condition depth cap (`32`), suspend data encoding/decoding, variable display truncation on UTF-8 char boundaries (`65536`), question bank draws, and SCORM 1.2/2004 status mapping (`coursecraft-lms/src/bridge.rs` and `u21_lms_status_tests`).
- **Archive save/open safety (`crates/format/src/lib.rs`)**: `save_project_to` and `open_project_from_with_limits` enforce safe relative paths, case-insensitive duplicate entry detection, precompressed storage, and `.take(limit + 1)` decompression caps.
- **CSV question import (`crates/engine/src/commands/csv_import.rs`)**: RFC 4180 parser handles quotes, CRLF, and UTF-8 BOM; enforces file/row/field caps (`5 MB`, `2000` rows, `4096` bytes/field); atomic import.
- **Publish packager (`crates/publish/src/lib.rs`)**: Strips templates from published `course.json`, collects all media roles, validates safe paths, embeds permitted system fonts (checking OS/2 `fsType`), and emits SCORM 1.2 / 2004 / cmi5 / xAPI / LTI / Web manifests.
- **LTI 1.3 JWT verification (`crates/lti/src/jwt.rs`, `lib.rs`)**: Enforces RS256 only via `ring`, checks `iss`/`aud`/`azp`/`exp`/`iat`/`nonce`/`message_type`/`version`/`deployment_id`, DER bounds, and 64 KiB token cap with zero panics.
- **Media & DOCX decoders (`crates/media/src/`, `crates/pptx/src/docx.rs`)**: Raster dimension/byte caps checked before decode; GIF/WebP capped at 300 frames / 256 MiB; SVG capped at 5 MiB / 20,000 elements with external hrefs disabled; WebVTT and font parsers bounded and UTF-8 safe.
- **UTF-8 text & string manipulation (`crates/course/src/text.rs`, `strings.rs`)**: Character-indexed (`Vec<char>` / `char_indices()` / `.get()`), safe against multi-byte UTF-8, emoji, combining marks, `ß`, and Turkish `İ` case-folding expansion.
- **Editor UI static safety (`crates/ui-egui/src/`)**: Zero production `.unwrap()`/`.expect()`/`panic!`/`todo!`/`unimplemented!`; all `.clamp` bounds guarded; all 186 UI-dispatched engine command IDs and top-level parameter keys verified against `crates/engine`; Preferences, Variables, Find & Replace, Crop, Grid & Guides, and Spell Check (`crates/spell`) core paths verified clean.
- **Desktop version history & autosave mechanics (`apps/coursecraft/src/versions.rs`, `autosave.rs`)**: Atomic `.part` copy + rename, safe snapshot ID validation blocking traversal, chunked byte comparison, and retention pruning verified sound.
