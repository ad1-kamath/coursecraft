# M48 Report — Editor Feedback from 0.6.5

**Milestone:** M48 (Editor feedback from 0.6.5: split buttons, slide tabs, layer bar, no-fill effects — pending release)  
**Plan:** [`docs/testing/m48-plan.md`](m48-plan.md)  
**Scope:** Four editor UX and rendering fixes reported on 0.6.5 across steps `S1`–`S5`: two-part ribbon split buttons with separate hover highlights and wider small-split arrow hit targets (`S1`, GitHub issue #17), a single italic preview document tab with pinning, horizontal overflow scroll, and O(1) revision-cached sync (`S2`), a dedicated wrapping canvas layer bar above the slide and rulers (`S3`), outline-only shadow and glow rendering when fill is off (`S4`), and greyed inspector Shadow/Glow controls with explanatory notes when both fill and outline are off (`S5`).
