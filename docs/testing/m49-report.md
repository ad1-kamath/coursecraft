# M49 Report — Group Animations, Slide Master Animations, and macOS Dark App Icon

**Milestone:** M49 (Group animations as one unit, slide master animations, and macOS dark app icon — pending release; ships alongside the matching-dropdown fix already on `main`, merge `0eb8501`)  
**Plan:** [`docs/testing/m49-plan.md`](m49-plan.md)  
**Scope:** Two contributor-reported animation gaps (reported by Luca) plus the macOS 26+ Dark app icon, across steps `S1`–`S6`: group-level `entrance`/`exit`/`emphasis` fields in the model, validator, command engine, and PowerPoint import (`S1`), unified group animation sampling, exit liveness, mesh post-pass, and offscreen unified-opacity fade compositing in runtime and renderer (`S2`), group animation controls across the Animations ribbon, Animate inspector, timeline group bar, canvas preview, timeline playback, and Animation Painter (`S3`), slide master object and master group animations in runtime, renderer, and accessibility tree while remaining non-interactive, unfocusable, and event-free (`S4`), Master View timeline, Animations ribbon, Animate inspector, Animation Painter, and playback support (`S5`), and the clean-room `CourseCraft.icon` bundle, pre-compiled `Assets.car`, and macOS bundle packaging (`S6`).
